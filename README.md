# One Line, Best Line

Entry for make.fun's "One Line, Best Line" bounty
(https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d).

The program writes exactly one line of text to `/output/entry.txt`:

> I bought a cactus because I heard they thrive on neglect, and honestly, it's the healthiest relationship I've ever had.

Pure Python standard library, no network, fully deterministic.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
